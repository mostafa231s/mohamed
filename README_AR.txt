تطبيق صدقة جارية على روح محمد معوض — مشروع Android Studio

هذا مجلد مشروع جاهز للبناء، وليس ملف APK مُجمّعًا بعد.

لإخراج APK:
1) ثبّت Android Studio على الكمبيوتر.
2) افتح Android Studio ثم Open واختر مجلد SadaqaMohamedAndroid بعد فك ضغطه.
3) انتظر انتهاء Gradle Sync وتنزيل أدوات أندرويد المطلوبة.
4) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) بعد اكتمال البناء اضغط Locate لفتح مجلد APK، وغالبًا يكون:
   app/build/outputs/apk/debug/app-debug.apk
6) ارفع ملف app-debug.apk إلى MediaFire.

ملاحظات:
- التطبيق يفتح صفحة الموقع المضمّنة داخله.
- المصحف الصوتي ومواقيت الصلاة وبعض الخدمات تحتاج الإنترنت.
- تحديد الموقع قد يحتاج موافقة المستخدم، حسب الجهاز وإصدار أندرويد.
- ملف APK الناتج من Build APK(s) نسخة تجريبية مناسبة للاختبار والمشاركة؛ للنشر الرسمي يلزم إعداد توقيع إصدار Release.
